# OpenWrt Пакет и Готовые APK для Mieru Client

Данный репозиторий содержит скомпилированный пакет OpenWrt для клиента `mieru` (v3.34.1) и веб-интерфейса LuCI, полностью оптимизированный для Xiaomi Mi Router 3G и роутеров на MIPS-архитектуре (`mipsel_24kc`, target `ramips/mt7621`, OpenWrt 25.12.1).

Пакеты собраны через официальный OpenWrt SDK с принудительным отключением CGO (`CGO_ENABLED=0`) и отключением `MIPS16` для корректной и стабильной работы Go-рантайма на MIPS-архитектуре.

---

## 1. Быстрая установка на роутер (одной командой)

Для установки откройте терминал (SSH) вашего роутера и выполните следующую команду:

```bash
wget -qO- https://raw.githubusercontent.com/alexxttss/mieru-openwrt/main/install.sh | sh
```

Скрипт автоматически:
1. Скачает скомпилированные `.apk` файлы из вашего репозитория во временную папку `/tmp`.
2. Установит их с помощью встроенного пакетного менеджера `apk` (автоматически разрешив зависимости, такие как `ucode` и `rpcd`).
3. Создаст дефолтный UCI-конфиг `/etc/config/mieru` (если его не существовало).
4. Запустит сервис Mieru и систему фонового мониторинга.

## 2. Структура репозитория

- `packages/` — директория с готовыми скомпилированными APK-пакетами:
  - `mieru-3.34.1-r1.apk` — основной бинарный файл клиента Mieru и служба procd.
  - `luci-app-mieru-0.260808.28259.apk` — плагин веб-интерфейса LuCI (написан на JS/ucode, с поддержкой импорта ссылок `mierus://`).
  - `luci-i18n-mieru-ru-0.260808.28259.apk` — русская локализация для веб-интерфейса.
- `package/` — исходный код структуры пакетов OpenWrt (для сборки в SDK):
  - `package/network/services/mieru/` — Makefile сборки клиента, UCI-конфиг, procd init-скрипт и ucode-монитор трафика/пинга.
  - `package/network/services/luci-app-mieru/` — исходные коды LuCI-интерфейса и ubus-контроллера.
- `install.sh` — скрипт быстрой установки.

## 3. Настройка клиента Mieru

### Способ А: Через веб-интерфейс LuCI (Рекомендуется)
1. Откройте панель управления роутером в браузере.
2. Перейдите во вкладку **Службы** -> **Mieru Client** (Services -> Mieru Client).
3. **Быстрый импорт по ссылке (NEW)**:
   - Скопируйте ссылку подписки или сервера формата `mierus://...` (например: `mierus://username:password@1.2.3.4?profile=default&port=2012&protocol=TCP&multiplexing=MULTIPLEXING_HIGH`).
   - На первой вкладке **Общие настройки** вставьте её в синий блок **«Импорт по ссылке»** и нажмите **«Импортировать ссылку»**.
   - *Или* нажмите верхнюю кнопку **«Импорт ссылки / JSON»**, вставьте ссылку и нажмите **«Импорт и применение»**. Все параметры (сервер, порт, имя пользователя, пароль, протокол) подставятся автоматически!
4. При ручном вводе: введите IP-адрес вашего сервера, порт, имя пользователя, пароль и выберите протокол (TCP или UDP).
5. Нажмите кнопку **Сохранить и применить** (Save & Apply).
6. На этой же странице в режиме реального времени отображается **Общий трафик** (`8.26 ГБ (6.19 ГБ ↓ / 2.07 ГБ ↑)`), задержка RTT, статус подключения, количество активных соединений и нагрузка на систему.

### Способ Б: Через консоль UCI
Вы можете настроить параметры в файле `/etc/config/mieru` вручную или с помощью команд UCI:

```bash
# Включение клиента
uci set mieru.main.enabled='1'

# Параметры подключения к серверу
uci set mieru.main.server='IP_ВАШЕГО_СЕРВЕРА'
uci set mieru.main.port='ПОРТ_СЕРВЕРА'
uci set mieru.main.username='ИМЯ_ПОЛЬЗОВАТЕЛЯ'
uci set mieru.main.password='ПАРОЛЬ'
uci set mieru.main.protocol='TCP' # Или 'UDP'

# Локальные порты и настройки
uci set mieru.main.socks5_port='1080' # Локальный SOCKS5 порт
uci set mieru.main.mtu='1400'
uci set mieru.main.log_level='INFO'

# Применить изменения и перезапустить сервис
uci commit mieru
/etc/init.d/mieru restart
```

## 4. Управление службой через терминал

Сервис полностью интегрирован с системой инициализации `procd` в OpenWrt:

- **Запуск**: `/etc/init.d/mieru start`
- **Остановка**: `/etc/init.d/mieru stop`
- **Перезапуск**: `/etc/init.d/mieru restart`
- **Перезагрузка конфигурации**: `/etc/init.d/mieru reload`
- **Статус службы**: `/etc/init.d/mieru status`
- **Включение автозапуска**: `/etc/init.d/mieru enable`
- **Отключение автозапуска**: `/etc/init.d/mieru disable`

## 5. Интеграция с системами обхода блокировок (SOCKS5, Подкоп, Netshift)

Mieru Client запускает локальный SOCKS5-прокси на роутере. По умолчанию используется порт `1080` (его можно изменить в UCI или LuCI). 
Также в конфигурации по умолчанию включена опция `socks5ListenLAN` (прослушивание локальной сети), что позволяет другим устройствам в вашей домашней сети использовать IP-адрес роутера и порт `1080` как SOCKS5-прокси напрямую.

Для прозрачного туннелирования и обхода блокировок трафика с самого роутера вы можете использовать популярные утилиты:

### А. Интеграция с "Подкоп" (Podkop)
Скрипт **Подкоп** (автор *IT-Dog*) позволяет автоматически направлять трафик к заблокированным ресурсам через сторонний прокси:
1. Установите и настройте Подкоп на вашем роутере.
2. В интерфейсе LuCI перейдите в меню **Службы** -> **Подкоп** (Services -> Podkop).
3. Во вкладке настроек исходящих соединений выберите тип прокси **SOCKS5**.
4. Укажите адрес сервера: `127.0.0.1` и порт: `1080` (или порт, указанный в настройках Mieru).
5. Сохраните и примените настройки. Все запросы к сайтам из списка блокировки будут автоматически уходить через туннель Mieru.

### Б. Интеграция с Netshift
**Netshift** — это современная система маршрутизации трафика на OpenWrt:
1. Перейдите в веб-интерфейс Netshift.
2. Откройте вкладку **Шлюзы** (Gateways) -> **Добавить шлюз** (Add Gateway).
3. Задайте имя (например, `Mieru_Proxy`), выберите протокол **SOCKS5**, укажите хост `127.0.0.1` и порт `1080`.
4. В разделе **Правила** (Rules) создайте политику маршрутизации, указав в качестве шлюза созданное подключение `Mieru_Proxy` для определенных списков доменов (например, списков антицензуры) или IP-адресов.

### В. Использование с vpn-policy-routing / PBR
Если вы используете классическую маршрутизацию по политикам (Policy Based Routing / PBR):
1. Вам потребуется SOCKS5-to-TUN клиент (например, `tun2socks` или `redsocks`).
2. Настройте `tun2socks` на перенаправление трафика интерфейса `tun0` на `127.0.0.1:1080`.
3. В интерфейсе PBR (vpn-policy-routing) настройте правила перенаправления трафика для определенных доменов или адресов на интерфейс `tun0`.
