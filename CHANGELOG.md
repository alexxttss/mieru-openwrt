# История изменений пакета OpenWrt Mieru

## [1.0.0-1] - 17.07.2026

- Первоначальный релиз пакета для OpenWrt 25.12.1.
- Полная интеграция с системой инициализации `procd`.
- Динамическая генерация конфигурационного файла `/var/etc/mieru_client_config.json` на основе UCI (`/etc/config/mieru`) с помощью библиотеки `jshn.sh`.
- Поддержка кросс-компиляции с использованием Go (`golang-package.mk`).
- Интеграция фонового мониторинга трафика, пинга и статуса на ucode.
- Создание веб-интерфейса управления LuCI с поддержкой резервных копий и русского языка.
