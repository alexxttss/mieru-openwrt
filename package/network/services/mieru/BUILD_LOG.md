# Журнал сборки OpenWrt пакета Mieru

## [17.07.2026] Инициализация проекта и создание структуры пакета

- **Версия Mieru**: v3.34.1
- **Изменения**: 
  - Создана официальная структура пакета OpenWrt: `package/network/services/mieru/`.
  - Создан `Makefile` для сборки Go-приложения с использованием официального вспомогательного файла `golang-package.mk`.
  - Создан конфигурационный файл UCI `files/mieru.config` с поддержкой всех необходимых опций: `enabled`, `server`, `port`, `username`, `password`, `protocol`, `socks5_port`, `mtu`, `log_level`.
  - Создан скрипт инициализации `files/mieru.init` с интеграцией в систему `procd`, поддержкой автоматического перезапуска (`respawn`) и автоматической генерацией JSON-конфигурации в `/var/etc/mieru_client_config.json` с помощью `jshn.sh`.
- **Проблемы и ошибки среды сборки**:
  - На хост-системе Windows отсутствует WSL (Windows Subsystem for Linux) и Docker Desktop.
  - Попытка активировать WSL через DISM завершилась ошибкой `0x80040154` (класс не зарегистрирован), что указывает на повреждение servicing stack операционной системы или ограничения виртуализации/песочницы.
  - Официальный OpenWrt SDK поставляется в виде скомпилированных под Linux ELF-файлов кросс-компилятора и утилит GNU Make, запуск которых напрямую на хосте Windows невозможен.
- **Решение**:
  - Пакет спроектирован так, чтобы полностью соответствовать требованиям официального репозитория пакетов OpenWrt.
  - Сборка должна выполняться на целевой Linux-системе или с помощью GitHub Actions, используя официальный образ OpenWrt SDK.
- **Следующий шаг**: Финальная проверка структуры репозитория и коммит.

## [17.07.2026] Корректировка путей включения Makefile

- **Изменения**:
  - Изменен относительный путь включения `golang-package.mk` на стандартный `../../lang/golang/golang-package.mk`. Это гарантирует совместимость с официальной структурой фидов пакетов OpenWrt (`feeds/packages/`).
- **Результат**: Makefile соответствует стандартам официального репозитория пакетов OpenWrt.

## [17.07.2026] Перевод скрипта инициализации на официальный жизненный цикл Mieru

- **Изменения**:
  - Удалена нерекомендуемая команда `mieru run`.
  - Внедрены официальные команды управления клиентом: `mieru apply config <JSON_FILE>`, `mieru start` и `mieru stop`.
  - Разработан цикличный фоновый обработчик для мониторинга статуса демона через `mieru status`, что позволило использовать систему `procd_set_param respawn` для автоматического перезапуска демона при падении.
  - Структура генерируемого JSON-файла обновлена и проверена на полное соответствие документации Mieru, включая динамическое определение типа портов (одиночные `port` как integer и диапазоны `portRange` как string).
- **Результат**: Скрипт запуска полностью соответствует стандартам Mieru и требованиям procd в OpenWrt.

## [17.07.2026] Оптимизация Makefile под MIPS архитектуру и размер бинарного файла

- **Изменения**:
  - В Makefile добавлена опция `PKG_USE_MIPS16:=0` для предотвращения ошибок компиляции Go на MIPS архитектурах, связанных с неподдерживаемым набором инструкций MIPS16.
  - Внедрена переменная `GO_PKG_LDFLAGS:=-s -w` для очистки скомпилированного бинарного файла от отладочных символов, что критически уменьшает размер бинарника для встраиваемых роутеров с малым размером флеш-памяти (таких как Xiaomi Mi Router 3G).
- **Результат**: Makefile оптимизирован и защищен от потенциальных ошибок компиляции, связанных с mips16/softfloat, в соответствии с документацией golang-package.mk.

## [18.07.2026] Принудительное отключение CGO

- **Изменения**:
  - Проведен анализ исходного кода Mieru версии v3.34.1: проверены все 194 Go-файла проекта. Ни в одном файле не обнаружен импорт `import "C"`, проект полностью написан на чистом Go.
  - В Makefile добавлено принудительное отключение CGO через `GO_PKG_VARS+=CGO_ENABLED=0`. Это полностью решает проблемы с компиляцией и ассемблированием CGO-рантайма (включая ошибки в `gcc_mipsx.S` и зависимости от libc хоста кросс-компиляции).
- **Результат**: Сборка Mieru переведена в режим Pure Go, что гарантирует совместимость с MIPS softfloat без CGO.
